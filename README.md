# MILON — Our Memories | Class of 2026

Mobile-first Bengali digital yearbook for Panchagarh Government Technical School & College, Class 9 Vocational Computer Department.

## Files
- `index.html`: public website
- `style.css`: design and lightweight animations
- `app.js`: Firebase Realtime Database listeners and gallery UI
- `admin.html_1010.html`: Firebase Authentication admin and CRUD interface
- `database.rules.json`: UID-restricted Realtime Database rules
- `SETUP-BN.md`: Bengali setup and deployment guide

The project uses Firebase Web SDK from the official CDN. Image files are stored on an external host and added by direct HTTPS URL; Firebase Storage is not used.
